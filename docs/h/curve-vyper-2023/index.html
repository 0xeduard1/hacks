Curve pools (Vyper bug)

🛠️ Compiler / tooling bug
💥 $69Mabout $69M across several pools Jul 30, 2023dateEthereumchain🔴 trickyto understand

The pools had a reentrancy lock, but some versions of the Vyper compiler built it wrong. The lock silently did nothing.

  1. 🏰

    What was it?

    Curve is one of the largest exchanges for similar assets. Several pools were written in Vyper, a Python-like smart contract language.

  2. 💥

    What happened

    Attackers re-entered pool functions while they were still running and drained pools used by Curve, Alchemix, JPEG'D and Metronome.

  3. 🛠️

    The bug, in plain words

    In some Vyper versions, the nonreentrant guard used mismatched storage slots in different functions, so it never actually blocked reentry.

  4. 🛡️

    How it could have been stopped

    Track known compiler bugs, test the compiled contract's behavior, and treat the toolchain as part of the audit scope.

  5. 🧙

    The lesson for an auditor

    Your tools are part of the attack surface. Correct source code is not the same as correct bytecode.

Meet the monster: 🛠️ The Broken Tool

The source code is correct, but the compiler or another tool turns it into something different. A protection written in the code silently does nothing.
