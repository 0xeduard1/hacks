Euler Finance

🧮 Broken invariant Funds returned
💥 $197Mabout $197M, later returned Mar 13, 2023dateEthereumchain🔴 trickyto understand

A little-used donate function let users reduce their own collateral without checking if the position was still healthy.

  1. 🏰

    What was it?

    Euler was a large, well-audited lending protocol: deposit collateral, borrow against it.

  2. 💥

    What happened

    Using flash loans, the attacker donated collateral to the reserves to make his own position insolvent on purpose, then liquidated himself at a discount and walked away with the difference.

  3. 🧮

    The bug, in plain words

    donateToReserves did not run the same health check as every other function that touches collateral.

  4. 🛡️

    How it could have been stopped

    Every new function must preserve the core invariant: a position can never end up with more debt than collateral.

  5. 🧙

    The lesson for an auditor

    One overlooked edge case can sink a battle-tested protocol. New functions deserve the same scrutiny as the old ones.

Meet the monster: 🧮 The Rule Breaker

Every protocol has rules that must always be true ("debt never exceeds collateral"). One function, often a new one, forgets to check it.
