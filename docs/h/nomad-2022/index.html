Nomad Bridge

🥚 Bad initialization
💥 $190Mabout $190M Aug 1, 2022dateMulti-chain bridgechain🟡 mediumto understand

An upgrade made every message count as valid. Hundreds of copycats drained the bridge by copy-pasting the first attack.

  1. 🏰

    What was it?

    Nomad was a bridge that only released funds for messages proven against a trusted root.

  2. 💥

    What happened

    After an upgrade, a fake message passed the check. Once the first attacker showed how, anyone could copy the transaction, change the address to their own, and withdraw.

  3. 🥚

    The bug, in plain words

    The upgrade set the trusted root to zero, a value that the code then treated as valid for any message.

  4. 🛡️

    How it could have been stopped

    Review the configuration values of every upgrade, not just the code, and test that invalid messages still fail.

  5. 🧙

    The lesson for an auditor

    An upgrade is new code plus new settings. Audit both.

Meet the monster: 🥚 The Unhatched Egg

A contract (or an upgrade) starts life with missing or wrong settings: no owner, a zero value that means "trust everything", a setup function anyone can call.
