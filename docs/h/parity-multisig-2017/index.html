Parity Multisig

🥚 Bad initialization
💥 $150Mabout $150M frozen forever, not stolen Nov 6, 2017dateEthereumchain🟡 mediumto understand

A shared library contract was never initialized. Someone became its owner and destroyed it, freezing every wallet that depended on it.

  1. 🏰

    What was it?

    Parity's multisig wallets were tiny contracts that borrowed all their logic from one shared library contract.

  2. 💥

    What happened

    A user called the library's setup function, became its owner, then called its self-destruct function. The library vanished, and with it the logic of every wallet using it.

  3. 🥚

    The bug, in plain words

    The library itself was an uninitialized wallet, so anyone could claim it. Nobody expected the library to be used as a wallet.

  4. 🛡️

    How it could have been stopped

    Initialize (or lock) implementation and library contracts at deployment, and never leave a self-destruct reachable.

  5. 🧙

    The lesson for an auditor

    Shared code is a single point of failure. Check the setup of every contract, including the ones "nobody uses directly".

Meet the monster: 🥚 The Unhatched Egg

A contract (or an upgrade) starts life with missing or wrong settings: no owner, a zero value that means "trust everything", a setup function anyone can call.
