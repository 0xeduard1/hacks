Poly Network

🔑 Access control Funds returned
💥 $611M$611M, later returned Aug 10, 2021dateMulti-chain bridgechain🟡 mediumto understand

A cross-chain message could call a privileged function and replace the keeper that approves withdrawals. The attacker made himself keeper.

  1. 🏰

    What was it?

    Poly Network was a bridge that moved assets between blockchains, trusting a set of "keepers" to approve withdrawals.

  2. 💥

    What happened

    The attacker crafted a cross-chain message that told the bridge's manager contract to replace the keeper list with his own key, then approved his own withdrawals.

  3. 🔑

    The bug, in plain words

    A contract that could execute arbitrary cross-chain messages had the power to change who is in charge.

  4. 🛡️

    How it could have been stopped

    Never let a general-purpose message executor call admin functions. Separate powers and restrict who can change the keepers.

  5. 🧙

    The lesson for an auditor

    For every function that changes who is in charge, ask: who can reach this, directly or indirectly?

Meet the monster: 🔑 The Gatecrasher

A powerful function (change the owner, move funds, swap the admin) can be called by someone who should not be allowed to call it.
