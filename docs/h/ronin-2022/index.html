Ronin Bridge

🗝️ Compromised keys
💥 $624Mabout $624M Mar 23, 2022dateRonin / Ethereum bridgechain🟢 easyto understand

Withdrawals needed 5 of 9 validator signatures. Attackers got 5 private keys and signed the withdrawals themselves. Nobody noticed for six days.

  1. 🏰

    What was it?

    Ronin was the blockchain behind the game Axie Infinity, with a bridge that needed 5 of 9 validators to approve withdrawals.

  2. 💥

    What happened

    Attackers, later attributed by the FBI to North Korea's Lazarus Group, gained control of 5 validator keys and approved two huge withdrawals: 173,600 ETH and 25.5M USDC.

  3. 🗝️

    The bug, in plain words

    No code bug. Too few keys, too concentrated: four of the nine were run by the same company, so one more key was enough.

  4. 🛡️

    How it could have been stopped

    More independent signers, hardware security, monitoring of large withdrawals, and alerts that someone actually watches.

  5. 🧙

    The lesson for an auditor

    Perfect code still fails if the keys are weak. Security includes people and operations.

Meet the monster: 🗝️ The Key Thief

The code works as written, but the private keys that control it are stolen, often through phishing or social engineering. Whoever holds enough keys can sign anything.
