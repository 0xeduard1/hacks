Wormhole

💌 Signature verification
💥 $326Mabout $326M, covered by the backers Feb 2, 2022dateSolana / Ethereum bridgechain🔴 trickyto understand

The bridge on Solana trusted a fake "signatures already verified" account, so the attacker minted 120,000 wrapped ETH backed by nothing.

  1. 🏰

    What was it?

    Wormhole is a bridge: lock ETH on Ethereum, get wrapped ETH on Solana, backed one to one.

  2. 💥

    What happened

    The attacker passed in a fake account that claimed the guardians' signatures were already verified. The bridge believed it and minted wrapped ETH with nothing locked behind it.

  3. 💌

    The bug, in plain words

    The code relied on an input that only claimed a check had happened, instead of verifying the signatures itself.

  4. 🛡️

    How it could have been stopped

    Verify signatures directly and validate every account passed into a program, never trust one that only says "I'm verified".

  5. 🧙

    The lesson for an auditor

    Trust nothing the caller hands you. If a check matters, do it yourself.

Meet the monster: 💌 The Forger

The code accepts a message or approval without truly verifying who signed it, or trusts an input that only claims verification happened.
