The Gatecrasher

Access control: Walks through a door that should have been locked.

How it attacks

A powerful function (change the owner, move funds, swap the admin) can be called by someone who should not be allowed to call it.

How to defend

For every function ask: who can call this? Lock admin actions behind clear roles, multisigs and timelocks.
