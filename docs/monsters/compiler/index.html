The Broken Tool

Compiler / tooling bug: Hides inside the tools that build the code.

How it attacks

The source code is correct, but the compiler or another tool turns it into something different. A protection written in the code silently does nothing.

How to defend

Track known compiler bugs, test the compiled bytecode, not just the source, and avoid exotic versions.

Curve pools (Vyper bug)

Jul 30, 2023 on Ethereum 💥 $69M

The pools had a reentrancy lock, but some versions of the Vyper compiler built it wrong. The lock silently did nothing.
