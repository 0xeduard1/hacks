The Vote Buyer

Governance attack: Borrows a crowd of votes for one second.

How it attacks

Voting power is measured at the moment of the vote, so an attacker borrows tokens with a flash loan, votes, executes, and returns the loan in one transaction.

How to defend

Snapshot voting power in the past, add a delay between a vote passing and it executing.
