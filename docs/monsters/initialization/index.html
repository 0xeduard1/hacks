The Unhatched Egg

Bad initialization: Hatches a contract that was never set up properly.

How it attacks

A contract (or an upgrade) starts life with missing or wrong settings: no owner, a zero value that means "trust everything", a setup function anyone can call.

How to defend

Protect every initializer, initialize implementation contracts too, and review the config values of every upgrade.
