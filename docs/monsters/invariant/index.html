The Rule Breaker

Broken invariant: Finds the one function that forgets the golden rule.

How it attacks

Every protocol has rules that must always be true ("debt never exceeds collateral"). One function, often a new one, forgets to check it.

How to defend

Write the invariants down, check them in every function, and test them with fuzzing.
