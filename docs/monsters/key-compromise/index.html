The Key Thief

Compromised keys: Steals the keys instead of breaking the code.

How it attacks

The code works as written, but the private keys that control it are stolen, often through phishing or social engineering. Whoever holds enough keys can sign anything.

How to defend

More independent signers, hardware keys, strict operational security, and limits on what any key set can move.

Ronin Bridge

Mar 23, 2022 on Ronin / Ethereum bridge 💥 $624M
