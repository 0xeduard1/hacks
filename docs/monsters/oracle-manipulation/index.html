The Price Faker

Oracle manipulation: Makes a price lie just long enough to borrow everything.

How it attacks

A protocol trusts a price that can be pushed around, usually a thinly traded token. The attacker pumps it, uses it as collateral, and borrows real assets.

How to defend

Use robust oracles (time-weighted, multiple sources), cap collateral for thin markets.
