The Echo

Reentrancy: Calls back in before the contract finishes its own work.

How it attacks

A contract sends money (or calls another contract) before it updates its own records. The receiver calls back in, again and again, and each time the contract still thinks the money is there.

How to defend

Update state first, interact last (checks-effects-interactions), and use a reentrancy guard.
