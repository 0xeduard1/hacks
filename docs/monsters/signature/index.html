The Forger

Signature verification: Brings a fake note that says "already checked".

How it attacks

The code accepts a message or approval without truly verifying who signed it, or trusts an input that only claims verification happened.

How to defend

Verify signatures yourself, against the right signer, and never trust an account or flag that only says a check was done.
